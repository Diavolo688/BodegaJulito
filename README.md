# 🏪 Bodega Julito
### Sistema de gestión de ventas e inventario

**Proyecto académico – Fundamentos de Programación | Grupo 7**

## 📌 Descripción

Sistema desarrollado en Python para facilitar la gestión de productos, el control de inventario y el registro de ventas de la bodega «Bodega Julito».

## ⚙️ Funcionalidades

- Consultar productos, precios y stock.
- Agregar nuevos productos.
- Actualizar precios y cantidades.
- Eliminar productos del inventario.
- Registrar ventas y descontar automáticamente el stock.
- Consultar el registro y total de ventas.

## 🛠️ Tecnologías utilizadas

- **Python 3:** desarrollo del sistema.
- **Visual Studio Code:** edición del código.
- **Git y GitHub:** control de versiones y trabajo colaborativo.

## ▶️ Instalación y ejecución

Clonar el repositorio:

```bash
git clone https://github.com/Diavolo688/BodegaJulito.git
```

Ingresar a la carpeta:

```bash
cd BodegaJulito
```

Ejecutar el programa:

```bash
python sitema.Julio.py
```
